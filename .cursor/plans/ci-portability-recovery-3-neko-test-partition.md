## Steps

### 1. Add compile-time Neko batch selection

In the test registration layer, select eight disjoint batches only for Neko builds while retaining the normal all-suite behavior elsewhere. Exclude the image- and algorithm-heavy suites that Neko cannot load because their generated bytecode exceeds its VM function-scope limit before the runner starts; they remain covered on all other CI targets.

### 2. Execute every batch in CI

In `.github/workflows/main.yml`, compile and run each compatible Neko batch under the existing Neko matrix lane.
